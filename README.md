# Alliance Synoïa — aperçu

Version de travail du site, publiée pour pouvoir être parcourue et commentée.
Ce dépôt ne contient que le site construit : HTML, CSS, polices, images.

Les pages portent `noindex` et un `robots.txt` interdit l'indexation : c'est
un aperçu, pas le site public. Il sera supprimé une fois le site en ligne
sur alliance-synoia.org.

Sources et documentation : dépôt privé `alliance-synoia`.
